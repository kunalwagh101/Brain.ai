# F-10.15 Shared Channel Message Pins UAT

Story: `S-10.15.01`

Status: implementation in progress. No DONE/PASS claim until executable gates and authenticated browser evidence exist.

## Product acceptance

1. As a current organisation-channel writer, pin a normal root message and confirm exactly one pin appears in the Pins panel.
2. Repeat the same pin request and run concurrent/retry pin calls; confirm one database row and one UI pin.
3. Pin a thread reply. Open it from Pins and confirm Brain reopens the correct existing thread context.
4. Edit a pinned human message and confirm the pin resolves to the current edited body without changing immutable revision history.
5. Pin a visible agent-authored message and confirm pinning succeeds without granting human edit/retract authority over the agent message.
6. Retract a pinned human message and confirm the pin is removed in the same lifecycle; it must not remain as a tombstone pointer.
7. In a restricted channel, revoke a member and confirm the next pins read fails closed or returns no inaccessible pinned content.
8. Attempt pin/unpin as a read-only member, guest, revoked member, cross-tenant user and against a message from another channel; every mutation fails closed.
9. Confirm pin list order is newest-pin-first and message representation contains only existing safe fields; the pin table/API adds no copied body/attachment/evidence text.
10. From two authenticated users, pin/unpin remotely and confirm S-10.10 live refresh updates the selected channel without manual reload.
11. Confirm browser list/pin/unpin routes are same-origin WorkOS requests with no reusable backend bearer token.
12. Run migration upgrade/downgrade/re-upgrade and confirm only pin rows/table are affected.

## Required executable evidence

- focused backend pin/retry/tenant/revoke/retract tests;
- Alembic single-head + PostgreSQL upgrade/downgrade/re-upgrade;
- `npm run lint` and `npm run build`;
- `node --test tests/channel-pins-contract.test.mjs` and full frontend contracts;
- `python scripts/verify_board.py`;
- official WorkOS authenticated multi-user desktop/mobile/keyboard UAT.

Until every required gate passes, keep `S-10.15.01` out of DONE/PASSED.
