# F-10.28 In-browser engineering workspace — not implemented

These are proposed acceptance scenarios, not executed tests. No repository editor, terminal or coding sandbox is currently available in Brain.

- S-10.28.01: grant a developer one repository; prove they can browse that repository/ref and cannot list a second repo or a revoked branch.
- S-10.28.02: edit a file in an isolated workspace; show diff and conflict handling; prove a read-only member cannot write or publish; verify the resulting commit/PR and rollback.
- S-10.28.03: run a bounded test and coding agent; prove timeout, cancellation, network/secret denial, approval before privileged actions and tenant/user isolation.

Require real users, real access grants and an isolated runner before claiming any scenario passed.
