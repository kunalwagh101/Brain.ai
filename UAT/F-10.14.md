# F-10.14 Ephemeral Presence & Typing UAT

Story: `S-10.14.01`

Status: implementation in progress. No DONE/PASS claim until executable gates and authenticated browser evidence exist.

## Product acceptance

1. Open Brain in two authenticated accounts in the same organisation. Keep account A visible. Account B sees A as online in an organisation channel within the presence lease target.
2. Hide/close/offline account A and confirm A disappears after lease expiry without any exact last-seen timestamp being exposed.
3. In a restricted channel, grant then revoke B. Presence/typing for that channel must follow current membership immediately on the next read.
4. Open a 1:1 DM as a participant and confirm only the other participant's online state is available. An owner/admin who is not a participant cannot read that DM presence/typing context.
5. Type non-empty text in a channel composer. The other user sees "<name> is typing…" within the polling target; stop/clear/send and confirm it disappears by explicit clear or <=8-second expiry.
6. Repeat typing in a DM and confirm only the other participant can see it.
7. Hold a key/type rapidly and inspect network requests. Typing refresh is throttled and does not send one request per keystroke.
8. Switch channels/DMs, hide the tab and unmount/close the context; confirm the client best-effort clears typing while server expiry remains the fallback.
9. Inspect API payloads/database rows and confirm no draft text, keystrokes, message body, cursor position, IP/user-agent, reusable token or exact last-seen history is stored/returned.
10. Simulate concurrent heartbeat/typing refreshes and confirm one lease row per user/context rather than duplicate history.
11. Seed expired leases and confirm they never appear in reads and are opportunistically deleted.
12. Confirm all browser mutations use same-origin WorkOS BFF routes and cross-site mutations fail closed.
13. Run migration upgrade/downgrade/re-upgrade and confirm only ephemeral lease tables are affected.

## Required executable evidence

- focused backend presence/typing expiry, concurrency, restricted-channel and DM privacy tests;
- Alembic single-head + PostgreSQL upgrade/downgrade/re-upgrade;
- `npm run lint` and `npm run build`;
- focused presence/typing frontend source contracts and full frontend tests;
- `python scripts/verify_board.py`;
- official WorkOS authenticated two-user desktop/mobile/keyboard UAT.

Until every required gate passes, keep `S-10.14.01` out of DONE/PASSED.
